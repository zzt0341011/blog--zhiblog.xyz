1、先创建ssh密钥
配置用户名和邮箱，先git init
git config user.name "new_username"
git config user.email "new_email@example.com"
创建密钥
ssh-keygen -t rsa -C "your_email@example.com"
密钥添加到ssh-agent
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_rsa
cat文件将公钥添加到github

2、再创建空仓库,以此输入以下命令
echo "# blog3" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin git@github.com:zzt0341011/blog3.git
git push -u origin main

更新博客

git add .
git commit -m "add zhiblog.xyz"
git push -u origin main
git push -f origin main

3. 如果出错，全新提交方法，

rm -rf .git
git init
git add .
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/zzt0341011/blog-npvtunnel.dev.git
git push -f origin main
