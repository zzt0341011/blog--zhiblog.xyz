## What Are the Main Use Cases of ChatGPT?

1. **Writing assistance**: drafting, polishing, summarizing, expanding, and rewriting articles  
2. **Language translation and learning**: Chinese-English translation, grammar explanation, foreign language conversation practice  
3. **Programming and automation**: Python, frontend, web scraping, data analysis  
4. **Office productivity**: writing emails, preparing presentations, drafting proposals  
5. **Education and learning**: reviewing math problems, explaining complex concepts  
6. **Business thinking**: brainstorming, market analysis, project planning suggestions  
7. **Image/document understanding (Plus)**: chart interpretation, image OCR, PDF summarization  

## What Are the Key Features of ChatGPT?

1. **GPT-4 release (March 2023)**: Significantly improved text understanding, reasoning, and coding abilities compared with GPT-3.5  
2. **ChatGPT plugins system**: Supports browser, code interpreter, and third-party services (such as Wolfram, Expedia)  
3. **ChatGPT Enterprise launch**: Enterprise-focused features including custom models and private deployment  
4. **ChatGPT iOS/Android apps**: More convenient mobile access  
5. **Multimodal features**: Image input (Vision), file uploads, and voice conversation (available to Plus users)  

## ChatGPT Usage Tips

1. **Provide clear context**: “I’m writing a business plan. Please help me optimize the summary section.”  
2. **Use multi-turn iterative conversation**: “Please simplify the language above,” “Can you make it more humorous?”  
3. **Assign a role or style**: “Act as an English teacher and help me polish this TOEFL essay.”  
4. **Combine with file uploads (Plus)**: “Please summarize the key points of this PDF.”  
5. **Ask it to teach you**: “I want to process Excel data in bulk. How can I do it with Python?”  
6. **Use built-in custom GPTs**: For example, “Image Analysis Expert” or “Data Processing Assistant.”
