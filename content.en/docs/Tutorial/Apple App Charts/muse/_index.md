# How to Download and Install Muse on iPhone

## Meta’s Personal AI Agent (Muse from Meta)

Meta has released a personal AI Agent called **Muse**. Unlike traditional “question-and-answer” AI chatbots, its design goal is to **execute multi-step complex tasks on behalf of the user**.

### ✨ Key Features

* **From “answering” to “executing”**: Users can not only ask questions but also authorize it to book restaurants, manage emails, track budgets, monitor product prices, and even place orders automatically.
* **Cloud secure virtual machine environment**: Muse runs in an isolated cloud Linux virtual machine (Muse Secure Virtual Machine) equipped with a built-in browser and command-line shell. This allows it to access websites, operate web forms, or run scripts just like a human.
* **Multi-app ecosystem integration**: Supports deep integration with external ecosystems and apps (such as Calendar, Gmail, Instagram, Facebook, Notion, Shopify, Canva, etc.).
* **Long-running background work and memory**: Even after closing the app, Muse can continue monitoring tasks in the background and push notifications when there are major updates or when confirmation is needed.

### 🚀 Core Advantages

1. **Real operational capability**: Goes beyond pure text output and can use a web browser, CLI, and connected apps to deliver results directly.
2. **Proactive automation**: Can schedule timed or continuous background tasks (e.g., “automatically monitor competitor ad changes every Monday”).
3. **Safety approval mechanism**: Sensitive operations (such as payments, sending emails, canceling subscriptions) first trigger human confirmation (Human-in-the-loop) to prevent mistakes.

## Downloading Muse on iPhone

- **Meta’s personal AI agent (Muse from Meta)** has strict regional availability restrictions.
- **The knowledge management and infinite canvas software (Muse – Tool for Thought)** can be freely downloaded from the App Store in most countries worldwide.

Currently, Muse is only available for download in the App Stores of the following countries/regions:

* **United States**
* **Canada**
* **Japan** (recently expanded as a pilot region)

Therefore, if your Apple ID is not from one of the above countries, you need to prepare a US Apple ID.
